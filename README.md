# App de estudio: Variables en Python

Aplicación de consola para que un estudiante practique variables en Python mediante ejercicios interactivos.

## Qué hace

- Presenta **5 ejercicios** progresivos sobre variables.
- Permite escribir `pista` para recibir ayuda.
- Da retroalimentación inmediata (correcto/incorrecto).
- Muestra solución sugerida después de varios intentos.
- Entrega resumen final de desempeño.

## Cómo ejecutar

```bash
python3 app_estudio_variables.py
```

## Ejercicios incluidos

1. Crear una variable de texto.
2. Crear una variable numérica.
3. Operar con variables.
4. Actualizar una variable.
5. Imprimir una variable.

Puedes extender la lista editando `cargar_ejercicios()`.
